
# Day 3 - Google Ads Keyword Research

## Project Overview
This project demonstrates basic Google Ads campaign planning for a fictional online shoe store.

## Project Objectives
- Understand keyword research.
- Classify keywords by search intent.
- Understand keyword match types.
- Organize keywords into ad groups.
- Write sample Google Search advertisements.
- Identify negative keyword opportunities.

## Tools Used
- Google Sheets
- Microsoft Excel
- Google Ads concepts

## Project Files
- google_ads_keyword_research.xlsx

## Business Scenario
A fictional online shoe store wants to promote its running shoes and casual sneakers using Google Search Ads.

## Key Learning
I learned how to organize keywords, identify customer search intent, understand match types, and write relevant ad copy.

## Disclaimer
This is a simulated educational project.
No real Google Ads campaign was launched, and no actual advertising results are claimed.
